# Geografia

## Geografia Fizyczna i Ogólna

### Który ocean jest najgłębszy i posiada największą powierzchnię na Ziemi?
- [ ] Ocean Atlantycki
- [x] Ocean Spokojny
- [ ] Ocean Indyjski
- [ ] Ocean Arktyczny
> Wyjaśnienie: Ocean Spokojny (Pacyfik) ma powierzchnię ok. $165,2\text{ mln km}^2$, a jego najgłębszym miejscem jest Głębia Challengera w Rowie Mariańskim (ok. $10994\text{ m}$).

### Jakie jest najmniejsze pod względem powierzchni państwo świata?
- [ ] Monako
- [ ] San Marino
- [x] Watykan
- [ ] Liechtenstein
> Wyjaśnienie: Watykan zajmuje powierzchnię zaledwie ok. $0,49\text{ km}^2$.

### Które jezioro jest najgłębsze na świecie?
- [ ] Tanganika
- [x] Bajkał
- [ ] Górne
- [ ] Titicaca
> Wyjaśnienie: Jezioro Bajkał w Rosji ma maksymalną głębokość ok. $1642\text{ m}$.

### Jak nazywa się najwyższy wodospad na świecie?
- [x] Salto Angel
- [ ] Wodospady Wiktorii
- [ ] Niagara
- [ ] Tugela
> Wyjaśnienie: Salto Angel w Wenezueli ma wysokość ok. $979\text{ m}$.

### Który obszar uchodzi za najsuchszą pustynię na Ziemi?
- [ ] Sahara
- [ ] Pustynia Gobi
- [x] Atakama
- [ ] Kalahari
> Wyjaśnienie: Pustynia Atakama w Ameryce Południowej charakteryzuje się najniższymi średnimi opadami rocznymi na Ziemi.

### Jaki jest jedyny kontynent, na którym nie znajduje się żaden czynny wulkan?
- [ ] Europa
- [ ] Ameryka Południowa
- [x] Australia
- [ ] Afryka
> Wyjaśnienie: Australia jest jedynym kontynentem pozbawionym czynnych wulkanów na swoim obszarze lądowym.

### Jaką przybliżoną powierzchnię ma cała planeta Ziemia?
- [ ] $150\text{ mln km}^2$
- [ ] $361\text{ mln km}^2$
- [x] $510\text{ mln km}^2$
- [ ] $700\text{ mln km}^2$
> Wyjaśnienie: Całkowita powierzchnia Ziemi wynosi około $510,1\text{ mln km}^2$, z czego wody stanowią około $71\%$.

## Stolice Świata

### Co jest stolicą Australii?
- [ ] Sydney
- [ ] Melbourne
- [x] Canberra
- [ ] Brisbane
> Wyjaśnienie: Stolicą Australii od 1913 roku jest Canberra, wybrana w wyniku kompromisu pomiędzy rywalizującymi miastami Sydney i Melbourne.

### Jak nazywa się stolica Kanady?
- [ ] Toronto
- [ ] Montreal
- [x] Ottawa
- [ ] Vancouver
> Wyjaśnienie: Stolicą Kanady jest Ottawa, leżąca w prowincji Ontario.

### Które miasto jest stolicą Brazylii?
- [ ] Rio de Janeiro
- [ ] São Paulo
- [x] Brasília
- [ ] Salvador
> Wyjaśnienie: Stolicą Brazylii od 1960 roku jest Brasília, wybudowana od podstaw w głębi kraju.

### Jak nazywa się stolica Turcji?
- [ ] Stambuł
- [x] Ankara
- [ ] Izmir
- [ ] Bursa
> Wyjaśnienie: Stolicą Turcji jest Ankara od 1923 roku, kiedy ustanowiono ją w miejsce Stambułu po proklamowaniu republiki.

### Które miasto pełni funkcję stolicy Maroka?
- [ ] Kasablanka
- [ ] Marrakesz
- [x] Rabat
- [ ] Fez
> Wyjaśnienie: Stolicą polityczno-administracyjną Maroka jest Rabat, podczas gdy Kasablanka jest największym miastem i centrum gospodarczym.

## Geografia Europy i Azji

### Jak nazywa się najdłuższa rzeka w Europie?
- [ ] Dunaj
- [x] Wołga
- [ ] Ren
- [ ] Dniepr
> Wyjaśnienie: Wołga ma długość ok. $3530\text{ km}$ i płynie całkowicie na terytorium europejskiej części Rosji.

### Na granicy jakich dwóch państw leży Mount Everest ($8848\text{ m n.p.m.}$)?
- [ ] Indii i Chin
- [x] Nepalu i Chin
- [ ] Nepalu i Indii
- [ ] Bhutanu i Chin
> Wyjaśnienie: Szczyt Mount Everest leży w Himalajach na granicy państwowej Nepalu i Chińskiej Republiki Ludowej (Tybetu).

### Która cieśnina oddziela Azję od Ameryki Północnej?
- [ ] Cieśnina Gibraltarska
- [x] Cieśnina Beringa
- [ ] Cieśnina Malakka
- [ ] Cieśnina Bosfor
> Wyjaśnienie: Cieśnina Beringa łączy Morze Beringa z Oceanem Arktycznym, oddzielając półwysep Czukotka (Azja) od Alaski (Ameryka Północna).

### Przez ile państw przepływa lub stanowi ich granicę rzeka Dunaj?
- [ ] 6
- [ ] 8
- [x] 10
- [ ] 12
> Wyjaśnienie: Dunaj przepływa przez 10 krajów: Niemcy, Austrię, Słowację, Węgry, Chorwację, Serbię, Rumunię, Bułgarię, Mołdawię i Ukrainę.

## Rekordy Geograficzne Państw

### Które państwo na świecie posiada najdłuższą linię brzegową?
- [ ] Rosja
- [ ] Indonezja
- [x] Kanada
- [ ] Australia
> Wyjaśnienie: Kanada posiada najdłuższą linię brzegową na świecie o długości przekraczającej $202000\text{ km}$.

### Jak nazywa się największa pod względem powierzchni wyspa na świecie?
- [ ] Borneo
- [ ] Madagaskar
- [x] Grenlandia
- [ ] Nowa Gwinea
> Wyjaśnienie: Grenlandia zajmuje powierzchnię ok. $2,16\text{ mln km}^2$ i jest największą wyspą świata (Australia uchodzi geograficznie za kontynent).

### Które państwo w Afryce ma największą liczbę ludności?
- [ ] Egipt
- [ ] Etiopia
- [x] Nigeria
- [ ] RPA
> Wyjaśnienie: Nigeria jest najludniejszym krajem Afryki z populacją szacowaną na ponad $220\text{ mln}$ mieszkańców.

### W jakim państwie znajduje się czynny wulkan Etna?
- [ ] Grecja
- [x] Włochy
- [ ] Hiszpania
- [ ] Islandia
> Wyjaśnienie: Etna to czynny stratowulkan położony na wschodnim wybrzeżu Sycylii we Włoszech.
