## Kartografia i Geodezja

### Na mapie w skali $1:50\ 000$ odległość między dwoma punktami wynosi $4\text{ cm}$. Ile wynosi ta odległość w terenie?
- [ ] $1\text{ km}$
- [x] $2\text{ km}$
- [ ] $5\text{ km}$
- [ ] $20\text{ km}$
> Wyjaśnienie: Skala $1:50\ 000$ oznacza, że $1\text{ cm} = 500\text{ m} = 0{,}5\text{ km}$. Zatem $4\text{ cm} \times 0{,}5\text{ km} = 2\text{ km}$.

### Pole powierzchni jeziora na mapie w skali $1:100\ 000$ wynosi $3\text{ cm}^2$. Ile wynosi rzeczywista powierzchnia tego jeziora?
- [ ] $0{,}3\text{ km}^2$
- [x] $3\text{ km}^2$
- [ ] $30\text{ km}^2$
- [ ] $300\text{ km}^2$
> Wyjaśnienie: Skala liniowa to $1\text{ cm} = 1\text{ km}$. Skala powierzchniowa wynosi $(1\text{ cm})^2 = (1\text{ km})^2 = 1\text{ km}^2$. Stąd $3\text{ cm}^2 = 3\text{ km}^2$.

### Jeśli w Londynie ($UTC+0$) jest godzina 12:00 czasu słonecznego, która godzina czasu słonecznego jest na południku $45^\circ E$?
- [ ] 09:00
- [ ] 13:00
- [x] 15:00
- [ ] 18:00
> Wyjaśnienie: Różnica długości geograficznej wynosi $45^\circ$. Ponieważ $15^\circ = 1\text{ h}$, różnica czasu wynosi $\frac{45}{15} = 3\text{ h}$. Na wschodzie czas jest późniejszy: $12:00 + 3\text{ h} = 15:00$.

### Ile wynosi szerokość geograficzna Bieguna Północnego?
- [ ] $0^\circ$
- [ ] $45^\circ N$
- [x] $90^\circ N$
- [ ] $180^\circ N$
> Wyjaśnienie: Szerokość geograficzna mierzona jest od równika ($0^\circ$) do biegunów ($90^\circ N$ oraz $90^\circ S$).

### O ile średnio spada temperatura powietrza na każde $100\text{ m}$ wzrostu wysokości w troposferze (gradient pionowy)?
- [x] $0{,}6^\circ\text{C}$
- [ ] $1{,}5^\circ\text{C}$
- [ ] $3{,}0^\circ\text{C}$
- [ ] $5{,}0^\circ\text{C}$
> Wyjaśnienie: Średni pionowy gradient temperatury w atmosferze wzorcowej wynosi około $0{,}6^\circ\text{C}$ na $100\text{ m}$ wysokości.
