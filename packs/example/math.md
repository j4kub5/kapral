# Matematyka 

## Arytmetyka i Liczby

### Ile wynosi wartość wyrażenia $2 + 2 \times 2$?
- [ ] 8
- [x] 6
- [ ] 4
- [ ] 10
> Wyjaśnienie: Zgodnie z kolejnością wykonywania działań najpierw wykonujemy mnożenie: $2 \times 2 = 4$, a następnie dodawanie: $2 + 4 = 6$.

### Jaka jest wartość $\sqrt{256}$?
- [ ] 14
- [ ] 15
- [x] 16
- [ ] 18
> Wyjaśnienie: $\sqrt{256} = 16$, ponieważ $16^2 = 256$.

### Ile wynosi $5!$ (silnia z 5)?
- [ ] 20
- [ ] 60
- [x] 120
- [ ] 720
> Wyjaśnienie: Silnia $5! = 5 \times 4 \times 3 \times 2 \times 1 = 120$.

### Jaki jest Największy Wspólny Dzielnik (NWD) liczb 48 i 18?
- [ ] 2
- [ ] 3
- [x] 6
- [ ] 12
> Wyjaśnienie: Dzielniki 48: 1, 2, 3, 4, 6, 8, 12, 16, 24, 48. Dzielniki 18: 1, 2, 3, 6, 9, 18. Największy wspólny dzielnik to 6.

## Algebra i Równania

### Jakie są rozwiązania równania kwadratowego $x^2 - 5x + 6 = 0$?
- [ ] $x = -2$ oraz $x = -3$
- [x] $x = 2$ oraz $x = 3$
- [ ] $x = 1$ oraz $x = 6$
- [ ] $x = -1$ oraz $x = -6$
> Wyjaśnienie: Wyróżnik $\Delta = (-5)^2 - 4 \cdot 1 \cdot 6 = 25 - 24 = 1$. Pierwiastki to $x_1 = \frac{5 - 1}{2} = 2$ oraz $x_2 = \frac{5 + 1}{2} = 3$.

### Ile wynosi dziesiąty wyraz ciągu arytmetycznego, w którym $a_1 = 3$, a różnica $r = 4$?
- [ ] 36
- [x] 39
- [ ] 43
- [ ] 40
> Wyjaśnienie: Wzór na $n$-ty wyraz ciągu arytmetycznego: $a_n = a_1 + (n-1)r$. Dla $n=10$: $a_{10} = 3 + 9 \cdot 4 = 39$.

### Jaka jest dziedzina funkcji $f(x) = \frac{1}{x - 4}$?
- [ ] $\mathbb{R}$
- [x] $\mathbb{R} \setminus \{4\}$
- [ ] $(4, +\infty)$
- [ ] $\mathbb{R} \setminus \{0\}$
> Wyjaśnienie: Mianownik ułamka nie może być równy zero, więc $x - 4 \neq 0 \implies x \neq 4$.

### Rozwiązaniem nierówności $|x - 2| < 3$ jest przedział:
- [x] $(-1, 5)$
- [ ] $(1, 5)$
- [ ] $(-\infty, -1) \cup (5, +\infty)$
- [ ] $(-5, 1)$
> Wyjaśnienie: Nierówność $|x - 2| < 3$ jest równoważna $-3 < x - 2 < 3$. Po dodaniu 2 otrzymujemy $-1 < x < 5$, czyli $x \in (-1, 5)$.

## Geometria i Trygonometria

### Ile wynosi pole trójkąta równobocznego o boku długości $a = 6$?
- [ ] $9$
- [x] $9\sqrt{3}$
- [ ] $18$
- [ ] $36\sqrt{3}$
> Wyjaśnienie: Pole trójkąta równobocznego wynosi $P = \frac{a^2\sqrt{3}}{4}$. Dla $a = 6$: $P = \frac{36\sqrt{3}}{4} = 9\sqrt{3}$.

### Ile wynosi wartość $\sin(30^\circ)$?
- [x] $\frac{1}{2}$
- [ ] $\frac{\sqrt{2}}{2}$
- [ ] $\frac{\sqrt{3}}{2}$
- [ ] $1$
> Wyjaśnienie: Wartość funkcji sinus dla kąta $30^\circ$ wynosi $\frac{1}{2}$.

### Jaka jest długość przekątnej kwadratu o boku $a = 5\sqrt{2}$?
- [ ] 5
- [x] 10
- [ ] $5\sqrt{3}$
- [ ] 20
> Wyjaśnienie: Przekątna kwadratu dana jest wzorem $d = a\sqrt{2}$. Dla $a = 5\sqrt{2}$: $d = (5\sqrt{2}) \cdot \sqrt{2} = 5 \cdot 2 = 10$.

### Wskazówki zegara pokazują godzinę 3:00. Jaki jest miara kąta wypukłego między nimi?
- [ ] $60^\circ$
- [x] $90^\circ$
- [ ] $120^\circ$
- [ ] $180^\circ$
> Wyjaśnienie: Tarcza zegara to $360^\circ$ podzielone na 12 godzin ($30^\circ$ na godzinę). Odległość 3 godzin to $3 \cdot 30^\circ = 90^\circ$.

## Analiza Matematyczna

### Ile wynosi pochodna funkcji $f(x) = 3x^4 - 2x^2 + 5$?
- [x] $f'(x) = 12x^3 - 4x$
- [ ] $f'(x) = 12x^3 - 4x + 5$
- [ ] $f'(x) = 3x^3 - 2x$
- [ ] $f'(x) = 7x^3 - 4x$
> Wyjaśnienie: Korzystamy z reguły $(x^n)' = n x^{n-1}$. Stąd $f'(x) = 3 \cdot 4x^3 - 2 \cdot 2x + 0 = 12x^3 - 4x$.

### Jaka jest wartość granicy $\lim_{x \to 0} \frac{\sin(x)}{x}$?
- [ ] 0
- [x] 1
- [ ] $\infty$
- [ ] Nie istnieje
> Wyjaśnienie: $\lim_{x \to 0} \frac{\sin(x)}{x} = 1$ to fundamentalna granica wyrażenia nieoznaczonego $\left[\frac{0}{0}\right]$.

### Oblicz całkę oznaczoną $\int_{0}^{2} 3x^2 \, dx$.
- [ ] 4
- [ ] 6
- [x] 8
- [ ] 12
> Wyjaśnienie: Funkcją pierwotną dla $3x^2$ jest $F(x) = x^3$. Zatem $\int_{0}^{2} 3x^2 \, dx = [x^3]_{0}^{2} = 2^3 - 0^3 = 8$.

### Ile wynosi wartość logarytmu $\log_2(32)$?
- [ ] 4
- [x] 5
- [ ] 6
- [ ] 16
> Wyjaśnienie: Z definicji logarytmu $\log_2(32) = c \iff 2^c = 32$. Ponieważ $2^5 = 32$, wynik to 5.

## Rachunek Prawdopodobieństwa i Kombinatoryka

### Rzucamy dwa razy symetryczną monetą. Jakie jest prawdopodobieństwo wyrzucenia co najmniej jednego orła?
- [ ] $\frac{1}{4}$
- [ ] $\frac{1}{2}$
- [x] $\frac{3}{4}$
- [ ] 1
> Wyjaśnienie: Zbiór zdarzeń elementarnych $\Omega = \{(O,O), (O,R), (R,O), (R,R)\}$ ($|\Omega|=4$). Zdarzenia sprzyjające to 3 zdarzenia z co najmniej jednym orłem, więc $P = \frac{3}{4}$.

### Na ile sposobów można ustawić 4 osoby w kolejce?
- [ ] 8
- [ ] 12
- [x] 24
- [ ] 16
> Wyjaśnienie: Liczba sposobów to liczba permutacji zbioru 4-elementowego: $4! = 4 \times 3 \times 2 \times 1 = 24$.

### Ile wynosi wartość symbolu Newtona $\binom{5}{2}$?
- [ ] 5
- [x] 10
- [ ] 15
- [ ] 20
> Wyjaśnienie: $\binom{5}{2} = \frac{5!}{2!(5-2)!} = \frac{5 \cdot 4}{2 \cdot 1} = 10$.

### Jaka jest suma kątów wewnętrznych w pięciokącie wypukłym?
- [ ] $360^\circ$
- [x] $540^\circ$
- [ ] $720^\circ$
- [ ] $900^\circ$
> Wyjaśnienie: Suma kątów wewnętrznych w $n$-kącie wypukłym wynosi $(n - 2) \cdot 180^\circ$. Dla $n=5$: $(5 - 2) \cdot 180^\circ = 3 \cdot 180^\circ = 540^\circ$.
